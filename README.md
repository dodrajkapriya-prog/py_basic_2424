Factorial Calculator

A simple Python program that calculates the factorial of a given number. This project is designed to demonstrate basic Python programming concepts and provide a straightforward implementation of factorial calculation.

Features
Calculates the factorial of a given number.
Simple and easy-to-understand Python implementation.
Lightweight with no external dependencies.
Suitable for beginners learning Python.
Installation

Clone the repository:

git clone https://github.com/your-username/your-repository.git


Navigate to the project directory:

cd your-repository


No additional packages are required.

Requirements
Python 3.x
No external dependencies

You can verify your Python installation with:

python --version

Usage

Run the program using:

python factorial.py


Enter a number when prompted. The program will calculate and display its factorial.

Example
Enter a number: 5
Factorial of 5 is 120


For example:

5! = 5 × 4 × 3 × 2 × 1 = 120
